# Как создать каталог на WordPress

Учебный HTML-сайт для начинающего: 22 этапа, ручные действия и параллельное объяснение работы AI-агента на локальном прототипе Cerlab.

Открыть пособие: https://wwwparser.github.io/wordpress-catalog-guide/

Главы объясняют устройство WordPress, дочернюю тему Twenty Twenty-Five, GreenShift, типы записей, метаполя, категории, галерею, заявки, адаптивность, проверку и перенос на хостинг. Есть упражнения, мини-тест, поиск, переключение подходов и локальное сохранение прогресса.

Публикуются учебник, снимки прототипа и авторские исходники в `source/` и `downloads/authored-source.zip`. База WordPress, пароли, cookies и секреты не входят в репозиторий. Изображения исходного каталога отдельно не распространяются; снимки используются для объяснения результата с указанием референса.

Это статический учебник. Рабочий WordPress с PHP, базой и админкой не запускается на GitHub Pages.

Источники: [видео Nikita Iudin](https://www.youtube.com/watch?v=OmzKdzCdfBA), [Cerlab](https://cer-lab.ru/). Прототип — самостоятельная реализация показанного подхода; исходный Figma и код плагина автора не были предоставлены.
