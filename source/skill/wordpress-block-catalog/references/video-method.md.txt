# Что показано в источнике

Источник: [видео Nikita Iudin](https://www.youtube.com/watch?v=OmzKdzCdfBA), 4:36, опубликовано 12.10.2026. Референс: [Cerlab](https://cer-lab.ru/). Домен читается на кадрах админки; публичный сайт подтвердил структуру и пути темы/плагинов.

| Время | Наблюдение | Практическое решение |
|---|---|---|
| 00:00–00:30 | Завершённый фриланс-проект каталога, ИИ использован для части задач | ИИ помогает создавать код, но не заменяет архитектуру и проверку |
| 00:30–01:23 | Figma, Auto Layout, desktop/tablet/768/mobile, 5–6 основных страниц и шаблоны товаров | Проектировать адаптивные компоненты до переноса в WordPress |
| 01:03–01:34 | Общая страница каталога с фильтрацией отложена из-за индивидуальности категорий | Категории оформлять отдельными редактируемыми страницами |
| 01:23–01:44 | Тёмная палитра выбрана для высокого ценового сегмента | Этот выбор относится к Cerlab, а не ко всем WordPress-сайтам |
| 01:57–02:28 | ИИ-прелоадер, 3D-изображение плит, видео, микроанимации | Использовать только оправданные эффекты, без блокирования содержимого |
| 02:28–03:12 | Текстура товара, дополнительные фото, липкая правая часть, CPT отдельным плагином | Данные вне темы; карточка поддерживает несколько фотографий |
| 03:12–03:54 | Категории, товары, настройки; категории через GreenShift; артикул, категория, фото, характеристики | Понятный редактор для заказчика и метаполя товара |
| 03:54–04:36 | Twenty Twenty-Five и дочерняя тема | Редактировать дочернюю блочную тему, сохранять обновляемого родителя |

На публичном сайте обнаружены `twentytwentyfive-child`, `cerlab-core`, `greenshift-animation-and-page-builder-blocks`, шрифты Onest/Inter. На кадрах видны меню SEO и GreenShift; конкретный SEO-плагин по одному меню не установлен. Не считать его обязательным.

Из видео нельзя достоверно восстановить промпты автора, модель ИИ, исходники `cerlab-core`, архитектуру всех настроек, полный Figma-файл и процесс публикации. Эти детали при новой реализации нужно спроектировать, а не выдать за факты видео.

Главная референса: 3D-баннер, логотипы производителей, индукционное видео, пять категорий, новинки, популярное, форма, подвал. Новинки: Rapolano, Pietra Di Gre Fine, Perlino Bianco, Mont Blanc. Популярное: Vulcano, Or, Macchia Vecchia Rain, Acero. В админке видео видно 74 товара; MVP с восемью образцами не является полной миграцией.
